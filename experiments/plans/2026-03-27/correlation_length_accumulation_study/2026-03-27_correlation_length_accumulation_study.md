# 计划：相关长度与积累策略对采集性能的影响研究

**日期**：2026-03-27
**背景**：导师指出当前系统按单个 C/A 码周期（1023 芯片 = 1 ms）做相关，积累能量有限，建议探讨将相关长度拉长（例如 20 ms）对采集性能的提升效果。
**核心问题**：相关积累长度从 1 ms 延伸到 20 ms（一个导航比特周期）时，信噪比和峰值能量如何变化？相干积累与非相干积累各自的增益和局限是什么？

---

## 现状分析

| 参数 | 当前实现 |
|------|---------|
| 单段相关长度 | 1023 芯片（1 ms） |
| 积累方式 | 非相干积累（每段取 `\|correlation\|²` 后累加） |
| 默认积累时长 | 10 ms（`cfg.noncoherent_ms = 10`） |
| 核心文件 | `matlab/functions/run_prn_acquisition.m` |

**非相干积累的问题**：每个 1 ms 段取模平方后丢弃相位信息，相位无法跨段叠加，理论增益为 $\sqrt{N}$（N 为段数），而相干积累理论增益为 $N$。

---

## 理论背景

### GPS 导航比特结构

```
1 导航比特 = 20 ms = 20 个 C/A 码周期
1 C/A 码周期 = 1 ms = 1023 芯片
```

- 在同一个导航比特内，C/A 码的调制相位不变（比特值固定为 +1 或 -1）
- 跨比特边界时，相位会翻转 180°
- **相干积累的上限**：20 ms（一个比特周期），超出此边界将因比特翻转导致相干叠加变为相消

### 积累增益对比

| 积累方式 | 时长 | 理论 SNR 增益 | 限制 |
|---------|------|--------------|------|
| 非相干 | 10 ms（当前） | ~$\sqrt{10}$ ≈ 3.2 倍 | 无比特跳变问题 |
| 非相干 | 20 ms | ~$\sqrt{20}$ ≈ 4.5 倍 | 无比特跳变问题 |
| 相干 | 1 ms | 1 倍（基准） | — |
| 相干 | 20 ms | 20 倍 | 必须在单个比特内，需知比特边界 |
| 相干 + 非相干 | 20 × 20 ms | 理论最强 | 复杂度高 |

## 实验计划

### 阶段一：非相干积累长度扩展实验（建议优先完成）

**目标**：在现有非相干框架下，直接将 `cfg.noncoherent_ms` 从 10 ms 增大到 20 ms，观察峰值能量和次峰比变化。

**步骤**：
1. 使用同一段实测 IQ 数据，分别以 `noncoherent_ms` = [1, 5, 10, 20] 运行 `run_prn_acquisition`
2. 记录每种配置下：
   - 最大相关峰值（`max(search_map(:))`）
   - 次峰比（`peak_ratio`）
   - 采集成功/失败判决
3. 绘制峰值 vs. 积累时长曲线，与理论 $\sqrt{N}$ 增益对比

**预期现象**：
- 峰值随积累时长增大，但增速遵循 $\sqrt{N}$ 规律（而非线性）
- 次峰比提升，噪声基底相对降低

**修改点**：无需修改 `run_prn_acquisition.m`，仅更改调用脚本中的 `cfg.noncoherent_ms`。

---

### 阶段二：相干积累实现（单比特内）

**目标**：在单个 20 ms 比特窗口内实现相干积累，验证增益是否接近 20 倍（线性）。

**核心挑战**：
- 相干积累时保留复数相关结果直接相加，不取模平方
- 20 ms 内比特值固定，但未知（+1 或 -1），若比特为 -1 则所有相关值反相
- **解决方案**：先不管符号，直接相干积累后取模——若比特一致，峰值应正常出现

**步骤**：
1. 在 `run_prn_acquisition.m` 中增加一个 `coherent_ms` 参数（1~20 ms）
2. 在 Doppler 补偿后，对连续 `coherent_ms` 段做复数相关相加（不取模平方），然后对整体输出取 `\|·\|²`
3. 可选：在外层再套一层非相干积累（即 coherent + non-coherent 两级结构）
4. 对比 coherent=1 ms vs. coherent=20 ms 的采集图

**代码结构示意**：
```matlab
% 相干积累（在单比特内）
coherent_corr = zeros(1, samples_per_code);
for ms_idx = 1:coherent_ms
    segment = ...;
    mixed = segment .* carrier;
    corr = ifft(fft(mixed) .* conj(local_code_fft));
    coherent_corr = coherent_corr + corr;   % 复数直接累加（相干）
end
accumulated_power = accumulated_power + abs(coherent_corr).^2;  % 最后取模（非相干外层）
```

---

### 阶段三：比特边界问题与盲积累策略（可选进阶）

**问题**：实际采集时不知道比特边界在哪里，若数据段跨越比特边界，相干积累会退化。

**探索方向**：
- **盲搜索**：对不同的比特边界偏移（0~19 ms）都尝试相干积累，取最大峰值
- **差分相干积累（Differential Coherent）**：相邻段之间乘以共轭，消除比特符号影响
- **非相干代替**：20 ms 内仍做非相干，增益低但无需知道边界

## 评估指标

| 指标 | 说明 |
|------|------|
| 峰值功率（dB） | `20*log10(max(search_map(:)))` |
| 次峰比 | `peak_ratio = 主峰 / 次峰`，当前判决阈值 2.5 |
| 采集成功率 | 固定信噪比下不同积累策略的成功比例 |
| 峰值增益 | 与 1 ms 基准相比的倍数，对比理论预测 |

## 关键结论（预期）

1. **当前 10 ms 非相干积累已是合理基线**，提升到 20 ms 可获约 1.4× 额外增益
2. **相干积累（20 ms）理论增益远高于非相干**，但实现需要处理比特边界和相位一致性
3. **导师建议的方向本质是**：在信号弱时，是否可以通过更长积累替代更高功率发射
4. 优先完成阶段一（改动最小，结论最直接），再根据结果决定是否实现阶段二
